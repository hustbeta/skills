# 首登强制改密权限边界设计（脱敏快照）

## 目标与约束

- 修复入口 A 的首登强制改密权限边界。
- 保持现有请求 `username`、`new_password` 及响应 JSON 不变。
- 不重构整套登录模型，不新增数据库迁移。
- 入口 A 下的登录、验证码和令牌接口仍需支持未登录调用。

## 拟议方案

1. 从个人登录响应检查的精确豁免表中移除 `/entry-a/force-change-password`。
2. 保留入口 A 的通用未登录前缀规则，因为同一前缀下还有其它登录前接口。
3. 保留现有 `ForceChangePasswordHandler`：按请求正文查找用户，校验新密码后重置密码，并清除首登标记。
4. 保持入口 A 和入口 B 的路由挂载不变；本次需求只调整入口 A。

## 验收方案

- 入口 A 的正常首登改密仍返回原成功 JSON。
- 密码复杂度、用户不存在和新旧密码相同仍返回原错误 JSON。
- 入口 A 的登录、验证码和令牌接口仍可在登录前调用。
- 入口 B 的既有请求与响应回归通过。

## 非目标

- 不改变客户端请求字段或增加客户端步骤。
- 不把所有未登录接口迁移到普通会话认证。
- 不调整入口 B 的产品行为。
