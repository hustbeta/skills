# 企微智能表格到禅道同步设计（历史最小快照）

## 已确认范围

- 单个 Go 工具同步一个企微智能表格 view 到一个禅道执行。
- 小规模系统，单进程串行执行；用户明确接受不处理并发同步和队列容量上限。
- ID 为空时复用唯一精确同名任务属于已确认业务规则。
- 禅道位于受控内网，允许配置 HTTP base URL 并接受相应残余风险。
- 只同步 view 中可见记录，不允许退化为读取整张 sheet。
- 固定中文列；创建父子任务后把 ID 写回企微。

## 实施顺序

1. 配置与命令入口。
2. SQLite 回调队列与 SSE。
3. callback HTTP 服务。
4. 企微客户端和同步规则。
5. 最后使用真实企微、禅道环境验证接口契约并修正 fixture。

## 外部接口假设

- 企微 `get_records` 接收 doc、sheet、view 参数，并返回指定 view 当前可见记录。
- 禅道 `POST /executions/{id}/tasks` 创建任务；创建子任务时在请求体加入 `parent`。
- 固定列预检只检查列名是否存在；存在即可开始写入。
- 创建任务固定使用 `estimate=80`。

## 失败处理

- 企微或禅道鉴权失败时停止。
- 固定列缺失时停止；类型不同则按当前返回值尽量解析。
- 单行任务创建失败只跳过该行，继续其它记录。
