# Evidence Index

## 用户确认的范围

- 用户明确接受“小规模系统，不考虑并发”和不把队列容量治理作为本期阻塞项。
- 用户明确接受 ID 为空时复用唯一精确同名任务的所有权规则。
- 用户明确接受内网禅道可能只有 HTTP，不要求本期强制 HTTPS。
- 用户要求固定列发生类型不匹配时，在任何写入前停止，并给出列名、期望类型、实际类型和修复动作。
- `estimate=80` 是减少禅道维护工作的创建默认值；实际工时仍是主要统计口径。

## 外部契约状态

- 企微指定 view 的读取范围、分页和字段结构在设计阶段尚未通过真实接口确认。
- 禅道 17.4 v1 创建任务文档列出的字段包含 `module`、`name`、`assignedTo`、`pri`、`estimate`、日期等，不包含 create-time `parent`。
- 历史官方答复指出：父子关系需通过创建后的编辑/更新或其它经验证路径建立。
- 状态动作、未指派负责人和 direct parent 均需使用可删除临时任务验证。

## 数据安全边界

- 真实契约验证只保存脱敏结构和 fixture，不保存 token、人员真实姓名或业务正文。
- 如果真实接口不支持 view 过滤或 direct parent，必须停止并重新确认，不能静默改成整表同步或无父子关系。
